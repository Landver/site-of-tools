Scope

{{.Scope}}

What that means concretely. This catalog is hand-maintained from vendor documentation and it is deliberately conservative, because a wrong deletion is worse than a missed one: a stripped parameter that turned out to be functional breaks the page you were trying to reach, silently, and you have no way of knowing that is what happened.

  • It does not guess from the shape of a name. No regular expressions. A rule nobody can read at a glance is a rule nobody reviews.
  • Ambiguous names are scoped to a host or they are absent. ref is a tracker on some sites and a git branch on others, and nothing in the name separates the two.
  • Some known trackers are deliberately left in. Amazon's th and psc choose which product variant renders; Substack's publication_id and post_id read as record IDs; the Shopify group is identifiable only by host, and a Shopify storefront is an arbitrary custom domain. Wrong product beats a clean URL.
  • It will miss things. Regional ad networks especially. A URL that comes back unchanged has not been certified clean; it has been checked against this list.
