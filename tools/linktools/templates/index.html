Where does the URL go?

Parsing happens on the server and nothing is fetched: no request is made to the host in the URL you paste.

The URL does reach this server. The app redacts it before logging anything, but the web server in front may log full URLs like any other. Don't paste live credentials into any web tool, this one included.

If a URL must never leave your machine, use a client-side parser instead. Doing it here is what makes the same URL answer as a JSON API.

Using this from the terminal 
curl '{{.Base}}/?u=https%3A%2F%2Fexample.com%2F%3Fa%3D1%26a%3D2'

Anything that doesn't ask for text/html gets JSON. Parameters come back as an ordered array, not an object — an object would lose the order this page exists to preserve.
