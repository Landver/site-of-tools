Where does the URL go?

Parsing happens on the server and nothing is fetched: no request is made to the host in the URL you paste.

The URL does reach this server, so it passes through the ordinary web-server logs like any other URL. The value of the u parameter is redacted before anything is written down here, but don't paste secrets into any tool, including this one.

If you need a URL that never leaves your machine at all, a client-side parser is the right choice. The trade made here is a curl-able JSON API on the same URL, which client-side tools structurally cannot offer.

Using this from the terminal 
curl '{{.Base}}/?u=https%3A%2F%2Fexample.com%2F%3Fa%3D1%26a%3D2'

Anything that doesn't ask for text/html gets JSON. Parameters come back as an ordered array, not an object — an object would lose the order this page exists to preserve.
