Corpberry Link extension — privacy

Served from the application so it versions with the code rather than rotting in a document somewhere.

What the extension sends

When you choose Copy Short Link Address, the address of the link you right-clicked is sent to link.corpberry.com so an alias can be created for it. That is the whole feature; it cannot work without sending the URL.

When you choose Copy Clean Link Address, nothing is sent. Cleaning happens inside your browser against a rule table the extension caches.

What is stored

A short link is stored: the code, the destination, when it was created, the creating IP address (for abuse handling only, never shown or served), and a hit count. There is no account and no profile.

The extension stores your API key and server setting in the browser's own extension storage. That storage is not encrypted, and if you are signed into the browser it syncs to your other profiles.

What is not collected

No browsing history, no page content, no analytics, no advertising identifiers, no third-party trackers, and nothing at all from pages you merely visit. The extension has no permission to read any page: it acts only on a link you explicitly right-click.

Sharing

Nothing is sold, rented or shared with anyone.
