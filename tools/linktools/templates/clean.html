Which parameters does this touch?

The rules are curated and hand-maintained, not complete. They will miss regional ad networks, and they deliberately do not guess about parameters that are functional on some sites. A name alone does not settle it: ref=facebook is a tracker and ref=main picks a git branch, so the ambiguous names ship scoped to a host or they do not ship at all.

Affiliate tags are kept by default because removing one is a different act from removing a click ID: it takes the commission from whoever published the link. Sorting is off because it breaks any URL whose signature covers the query string as written. Wrappers are unwrapped unless you say otherwise, because the wrapper's own query is the one part of the link nobody wants.

Nothing here is a black box. Every rule is on one page: who sets each parameter, what it identifies, and the separate list of names that are never removed, with what breaks if they were.

Using this from the terminal 
curl '{{.Base}}/clean?u=https%3A%2F%2Fexample.com%2F%3Futm_source%3Dx'

Same URL, same rules. The removals come back as an ordered array carrying the rule name and the reason, not as a count.
