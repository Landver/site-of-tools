      What the parser does and does not do
      

        

          It is a tokeniser, not a shell. It understands the quoting
          forms that actually appear in a copied command and refuses everything else: no variables, no
          substitution. The input is untrusted text and the only safe way to read untrusted text is to not
          evaluate it.
        

        

          The URL comes back exactly as written, including a missing
          scheme. curl would quietly assume http there; inventing it here would
          hide the fact that the pasted command depended on that assumption, so it is reported as a finding
          instead.
        

      

    


    

      Using this from the terminal
      
curl '{{.Base}}/curl?u=https%3A%2F%2Fexample.com%2F'

      
The paste direction answers on the same path: --data-urlencode curl=… as a POST, or ?curl= for something with nothing secret in it. It returns the URL, the headers in the order they were written, and the full parse of the URL.
