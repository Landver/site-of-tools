Reading…
How the input is read

The shape of the input is detected rather than asked for: markup is parsed as HTML so the anchor text travels with the link, Markdown link syntax is read as Markdown, and anything else is scanned for bare URLs. Which of the three happened is reported with the result, because it changes what gets found.

Nothing is fetched. Every surveyed tool that does this job also requests every URL it finds, which is slower and is a different, riskier promise: it tells each destination that someone is auditing the links, from this server's address, before you have decided anything.

The pasted text is redacted before this server writes anything down, and the form posts rather than putting the paste in a URL. It still reaches the server to be parsed. Don't paste anything you would not send.

JSON API 
curl '{{.Base}}/extract' --data-urlencode 'text=see https://example.com'

GET with ?text= works too, for anything small enough to fit in a URL.
