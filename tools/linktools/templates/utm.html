What it does with a URL that is already tagged

An existing value is replaced, not appended. Two utm_source parameters on one URL is a real bug that analytics tools resolve inconsistently, and deliberately building one would be an odd thing for this page to do.

Leaving a field empty keeps whatever the URL already carries for that tag, and the result says which tags were already there. To drop a tag, delete it from the URL, or remove them all on the Clean page. Every other parameter on the URL, and the order it was in, is left exactly as you pasted it.

These five tags are visible to everyone the link is forwarded to, and they travel into other people's browser history and referrer headers. They describe a campaign, so keep them describing a campaign: a name that identifies one recipient turns a shareable link into a tracking pixel with a person's name on it.

Using this from the terminal 
curl '{{.Base}}/utm?u=https%3A%2F%2Fexample.com%2F&utm_source=newsletter'

The tagged URL comes back as url, with tags saying where each tag came from and notes for what trips analytics tools.
