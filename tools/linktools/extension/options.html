Corpberry Link

Needed only for Copy Short Link Address. Cleaning works without it. This key is stored in chrome.storage.sync, which is not encrypted and syncs to every Chrome profile signed into your Google account.

Leave blank for the default. Only https://link.corpberry.com and a loopback address (http://link.localhost:8080) are accepted — anything else falls back to the default, so a typo here can never send your key to someone else's server.
