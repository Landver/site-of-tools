Random tokens, passwords and UUIDs

Secrets for API keys, session tokens and test accounts, from your browser's cryptographic random source. Characters are drawn without modulo bias, and each result says how many bits of entropy it carries.

Using this from the terminal

Every tool here also answers a plain POST with JSON. From a terminal your input goes to this server, unlike on the page, which runs everything in your browser.

curl {{.Base}}/random -d kind=token -d bytes=32 -d format=base64url
  curl {{.Base}}/random -d kind=password -d length=24 -d sets=lower,upper,digits -d exclude_ambiguous=on
  curl {{.Base}}/random -d kind=uuid -d version=7 -d count=10

POST only. sets is a comma-separated list or a repeated field, and all four when left out. The API draws on this server, so the values travel over the network to you; this page makes them in your browser.
