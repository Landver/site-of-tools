What is this string?

Paste a token, key, certificate, hash or encoded value. The page lists what it could be, most likely first, with why, the hashcat mode where one is certain, and the page that reads it. Hashes of the same length can't be told apart by looking, so they are all listed.

POST only, up to 1 MiB. The API runs on this server; this page computes in WebAssembly.
