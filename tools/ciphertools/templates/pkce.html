PKCE generator and verifier (RFC 7636)

Generate high-entropy code_verifier and derived code_challenge pairs for OAuth 2.1 and OpenID Connect, or verify an existing challenge against a verifier. Everything runs in your browser.

{{template "cipher/engine" .}}
Using this from the terminal
{{template "cipher/engine-terminal"}}curl {{.Base}}/pkce/generate -d length=64 -d method=S256 curl {{.Base}}/pkce/verify -d code_verifier=your_verifier -d code_challenge=your_challenge -d method=S256

POST only, JSON API. S256 uses unpadded base64url(sha256(verifier)). Plain uses verifier directly (deprecated by OAuth 2.1).
