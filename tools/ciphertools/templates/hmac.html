Every common HMAC of a message at once. Paste the signature you received and it is checked in constant time against each one, and the page names the algorithm that matches.

Webhook signatures (GitHub, Stripe, Slack) are HMAC-SHA256 over the raw request body. Paste the body exactly as it arrived: parsed and re-serialised JSON has different bytes and will not match. GitHub's sha256= prefix is removed for you. Stripe signs timestamp.body and Slack v0:timestamp:body, so put that string in the message.

JSON API 
curl {{.Base}}/hmac --data-urlencode text@body.json -d key=secret -d expected=sha256=…

POST only. Fields: text, enc, key, key_enc (utf8, hex, base64, base64url), expected. --data-urlencode text@file sends the file byte for byte. The API runs on this server, so the key travels; the page above doesn't send it anywhere.
