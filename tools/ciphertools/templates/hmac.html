Checking a GitHub, Stripe or Slack webhook?

They sign the raw request body with HMAC-SHA256. GitHub's sha256= prefix is removed for you. Stripe signs timestamp.body and Slack v0:timestamp:body.

Using this from the terminal
{{template "cipher/engine-terminal"}}curl {{.Base}}/hmac --data-urlencode text@body.json -d key=secret -d expected=sha256=…

POST only. The API runs on this server; this page computes in WebAssembly.
