DPoP proof generator and verifier (RFC 9449)

Generate and verify Demonstrating Proof-of-Possession (DPoP) JWTs for OAuth 2.1, FAPI 2.0 and the Bluesky AT Protocol. Proofs bind sender requests to an asymmetric key pair. Private keys and tokens never leave your browser.

{{template "cipher/engine" .}}
Using this from the terminal
{{template "cipher/engine-terminal"}}curl {{.Base}}/dpop/generate -d htm=GET -d htu=https://api.example.com/user -d alg=ES256 curl {{.Base}}/dpop/verify -d token=eyJ... -d htm=GET -d htu=https://api.example.com/user

POST only, JSON API. Computes RFC 7638 jkt thumbprints, binds htm/htu, and validates access token hashes (ath).
