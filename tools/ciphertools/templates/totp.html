TOTP and HOTP codes

Paste a base32 secret or a whole otpauth:// URI to see the codes an authenticator app shows: previous, current and next, with a countdown. Add a code to check it against one step either side, the window most servers accept.

Using this from the terminal

Every tool here also answers a plain POST with JSON. From a terminal your input goes to this server, unlike on the page, which runs everything in your browser.

curl {{.Base}}/totp -d secret=JBSWY3DPEHPK3PXP -d code=123456
  curl {{.Base}}/totp --data-urlencode 'secret=otpauth://totp/Example:alice?secret=JBSWY3DPEHPK3PXP&issuer=Example'
  curl {{.Base}}/totp -d secret=JBSWY3DPEHPK3PXP -d mode=hotp -d counter=5

POST only. Other fields: algo (SHA1, SHA256, SHA512), digits, period, label, issuer, and now (unix seconds) for the codes at another moment. The API runs on this server, so the secret travels; this page doesn't send it anywhere.
