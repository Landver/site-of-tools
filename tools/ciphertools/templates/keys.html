Key generator and converter: RSA, ECDSA, Ed25519

Make a test key pair, or paste a key to read it and convert it: PEM, JWK and OpenSSH, with the SPKI fingerprint, the OpenSSH SHA256: fingerprint and the RFC 7638 JWK thumbprint.

{{template "cipher/engine" .}}
Using this from the terminal
{{template "cipher/engine-terminal"}}curl {{.Base}}/keys/generate -d type=ec-p256 curl {{.Base}}/keys/inspect --data-urlencode key@public.pem

POST only. type is ed25519, ec-p256, ec-p384, ec-p521, rsa-2048, rsa-3072 or rsa-4096. Generate has a stricter rate limit than the rest. The API runs on this server: a key it generates was made there and sent back, and a key you inspect travels to it, so give it public keys only. This page doesn't send anything anywhere.

openssl genpkey -algorithm RSA -pkeyopt rsa_keygen_bits:3072 -out key.pem

Read or convert a key

Reads PKCS#8, PKCS#1, SEC 1, SPKI and unencrypted OpenSSH PEM, a certificate's key, JWK and JWKS, and authorized_keys lines. A private key is converted too, but its private forms stay folded away, and the public JWK never carries d, p, q, dp, dq or qi.

{{if eq .Op "keys-inspect"}}{{if .Error}}{{template "cipher/error" .}}{{else}}{{template "cipher/keys-inspected" .}}{{end}}{{end}}
The same with openssl and ssh-keygen 
openssl pkey -in key.pem -noout -text                  # read a key
openssl pkey -in key.pem -pubout                       # public PEM from a private key
openssl pkey -in key.pem -pubout -outform DER | openssl dgst -sha256 -c   # SPKI SHA-256
ssh-keygen -y -f id_ed25519                            # OpenSSH public line from a private key
ssh-keygen -lf id_ed25519.pub                          # OpenSSH SHA256: fingerprint
