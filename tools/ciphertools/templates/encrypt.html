Encrypt and decrypt: AES-GCM, ChaCha20-Poly1305, AES-CBC

Encrypt text or bytes with a key you supply, or decrypt what an encrypt produced. The key is exact bytes, as hex or base64: 16, 24 or 32 for AES, 32 for ChaCha20-Poly1305. It is never padded or cut to fit.

No passphrase mode, because a passphrase is not a key. Make a random key on the Random page (32 bytes, hex), or derive one with Argon2id or PBKDF2 on the Passwords page: the last $ part of its output is a 32-byte key in base64, and the salt and parameters before it are what derive the same key again.

Output layout: nonce ‖ ciphertext ‖ tag for AES-GCM and ChaCha20-Poly1305 (12-byte nonce, 16-byte tag), iv ‖ ciphertext for AES-CBC (16-byte IV, PKCS#7 padding). Decrypt reads the same layout, so the output of one is the input of the other.

curl {{.Base}}/encrypt -d mode=decrypt -d algo=aes-gcm -d key=000102030405060708090a0b0c0d0e0f --data-urlencode data=…

POST only. algo is aes-gcm, chacha20-poly1305 or aes-cbc; key_enc hex or base64; enc (plaintext) utf8, hex or base64; data_enc auto, base64 or hex. Optional nonce (hex), aad and aad_enc. The API runs on this server, so the key travels; the page above doesn't send it anywhere.
