Base64, hex and base32 converter

Paste bytes in one encoding and get them in all the others. Base64 input can be any of the four variants, and the page says which one it saw. A bad character is reported with its offset, and bytes that aren't UTF-8 are shown as hex, never as garbled text.

Using this from the terminal

Every tool here also answers a plain POST with JSON. From a terminal your input goes to this server, unlike on the page, which runs everything in your browser.

curl {{.Base}}/encode -d from=hex -d text=48656c6c6f
  curl {{.Base}}/encode/basic -d mode=build -d user=Aladdin --data-urlencode 'password=open sesame'
  curl {{.Base}}/encode/basic -d mode=decode --data-urlencode 'header=Basic QWxhZGRpbjpvcGVuIHNlc2FtZQ=='

POST only. from is utf8, hex, base64, base64url or base32. The API runs on this server, so the input travels; this page doesn't send it anywhere.

HTTP Basic auth

The header is Basic plus base64 of user:password in UTF-8 (RFC 7617). That is an encoding, not encryption: anyone who sees the header can read the password.
