Base64, hex and base32 converter

Paste bytes in one encoding and get them in all the others. Base64 input can be any of the four variants, and the page says which one it saw. A bad character is reported with its offset, and bytes that aren't UTF-8 are shown as hex, never as garbled text.

HTTP Basic auth

The header is Basic plus base64 of user:password in UTF-8 (RFC 7617). That is an encoding, not encryption: anyone who sees the header can read the password.
