What is sent where

  • A tool call's arguments and its result pass through your AI provider and this server. Hosted connectors, such as claude.ai's and ChatGPT's, call from the provider's servers; local clients from your machine.
  • Cipher Tools' pages run in your browser and send nothing. Over MCP the cipher tools run on this server and keep nothing, but their inputs and outputs pass through your AI provider like any call's: use test keys, passwords and tokens, never live ones.
  • Each call is logged with the tool's name, its status, how long it took, the result's size, and the caller's IP address and client name. Never the arguments, the result or an error message, which can quote them.
  • Results built on third-party data carry an attribution list naming each source and its notice.

Rate limits

Per client address (an IPv6 address counts by its /64), and shared with each tool's JSON API: a call here spends the budget the same request to the tool's own site would. A refused call is an error result saying to try again in a few seconds. Hosted connectors share their provider's addresses, and so their budgets.
