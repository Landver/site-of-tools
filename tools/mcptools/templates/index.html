What is sent where

  • A tool call's arguments and its result pass through your AI provider and this server. Hosted connectors, such as claude.ai's and ChatGPT's, call from the provider's servers; local clients from your machine.
  • Cipher Tools' pages run in your browser and send nothing. Over MCP the cipher tools' inputs and outputs travel like any other call's, so use test material only: never a real password, key or token.
  • Each call is logged with the tool's name, the outcome, how long it took, the result's size, and the caller's IP address and client name. Never the arguments, the result or an error message, which can quote them.
  • Results built on third-party data carry an attribution list, the credits in this page's footer.

Rate limits

Per client address (an IPv6 address counts by its /64), and shared with each tool's JSON API: a call here spends the budget the same request to the tool's own site would. Each tool's rate and burst are listed beside it below. Every other message, such as tools/list, counts against {{with .Protocol}}{{.PerSecond}} a second (burst {{.Burst}}){{end}}, and all requests to /mcp from one address against {{with .PerIP}}{{.PerSecond}} a second (burst {{.Burst}}){{end}}. Some tools also have a budget every caller shares, of calls running at once or calls a second. A refused call is an error result saying to try again in a few seconds. Hosted connectors share their provider's addresses, and so their budgets.
