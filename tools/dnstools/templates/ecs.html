What scope means, and what each network was told

The same {{.Type}} query went to {{.Resolver}} {{.Asked}} times, each carrying a different network as its EDNS client subnet. Scope is what the answering side said about its own answer: 0 means it was not tailored to the network that asked. A scope equal to the prefix length we sent is also what a server that merely echoes the option returns, so only a length the zone shortens to its own block shows the network was read. The places are our labels for fixed prefixes, not measurements: these {{.Asked}} prefixes can show that answers differed, never that the split follows geography.
