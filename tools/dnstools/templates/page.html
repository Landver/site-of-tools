{{if eq $a "lookup"}} Nine record types at once, asked in parallel: A, AAAA, CNAME, MX, NS, TXT, SOA, CAA and HTTPS. Enter an IP to get its reverse (PTR) record instead. {{else if eq $a "consistency"}} Is your change live yet? This asks the zone's own nameservers directly (up to eight of them), with recursion off, and compares them against the public resolvers. No world map: one server can't honestly measure geography. {{else if eq $a "trace"}} Follows the delegation from a root server down to the zone that owns the name, asking each server directly with recursion off, and checks the DNSSEC chain itself against the IANA root keys rather than trusting a resolver's AD bit. Every hop is shown, with its server, glue and timing. {{else if eq $a "domain"}} Two things DNS can't tell you: which registrar holds this name and when it expires (RDAP), and which subdomains have had public certificates (Certificate Transparency). Both are public, and neither sends a packet at the domain. {{else}} SPF, DMARC, DKIM, MTA-STS, TLS-RPT and BIMI for a domain, plus whether its inbound mail servers are on a blocklist. SPF is checked against its 10-lookup limit: over it, SPF fails for every message, silently. {{end}}

Using this from the terminal

Same URL, content-negotiated: browsers get the page, everything else gets JSON.

{{if eq $a "lookup"}}

# every type at once (JSON)
curl 'https://dns.corpberry.com/?name=example.com'

# narrow to one type, from Quad9
curl 'https://dns.corpberry.com/?name=example.com&type=MX&resolver=quad9'

# reverse lookup — just pass the IP
curl 'https://dns.corpberry.com/?name=1.1.1.1'

{{else}}

curl 'https://dns.corpberry.com/{{$a}}?name=example.com'

{{if .Types}}

curl 'https://dns.corpberry.com/{{$a}}?name=example.com&type=MX'

{{end}} {{end}}
