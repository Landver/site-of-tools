Every record type at once, in one query: A, AAAA, CNAME, MX, NS, TXT, SOA, CAA and HTTPS, asked in parallel. Paste an IP instead and it turns into a reverse (PTR) lookup on its own.

{{/* Defaults to every type at once — picking one is narrowing, not the price of entry. */}} {{/* htmx toggles .htmx-request on the form while in flight. Shown to screen readers then and only then; sighted users get the button label and the dimmed results. */}} Querying every record type…
Using this from the terminal

Same URLs, content-negotiated: browsers get the page, everything else gets JSON.

# every type at once (JSON)
curl 'https://dns.corpberry.com/?name=example.com'

# narrow to one type, from Quad9
curl 'https://dns.corpberry.com/?name=example.com&type=MX&resolver=quad9'

# reverse lookup — just pass the IP
curl 'https://dns.corpberry.com/?name=1.1.1.1'
