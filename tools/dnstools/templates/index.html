Nine record types at once, asked in parallel: A, AAAA, CNAME, MX, NS, TXT, SOA, CAA and HTTPS. Enter an IP to get its reverse (PTR) record instead.

{{/* Defaults to every type at once — picking one is narrowing, not the price of entry. */}}
Using this from the terminal

Same URLs, content-negotiated: browsers get the page, everything else gets JSON.

# every type at once (JSON)
curl 'https://dns.corpberry.com/?name=example.com'

# narrow to one type, from Quad9
curl 'https://dns.corpberry.com/?name=example.com&type=MX&resolver=quad9'

# reverse lookup — just pass the IP
curl 'https://dns.corpberry.com/?name=1.1.1.1'
