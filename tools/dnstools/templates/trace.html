{{.Title}}

Start at a root server, ask with recursion off, follow each referral down to the zone that actually owns the name. Every hop is shown: which server answered, whether the referral carried glue, and how long it took. The DNSSEC chain is verified here, key by key, against the IANA root trust anchors, not read off a resolver's AD bit.

{{/* htmx toggles .htmx-request on the form while in flight. A bare "…" reads as decoration, not as "working". */}} Walking down from the root…
Using this from the terminal

Same URL, content-negotiated: browsers get the page, everything else gets JSON.

curl 'https://dns.corpberry.com/trace?name=example.com'

curl 'https://dns.corpberry.com/trace?name=example.com&type=MX'

The nearest equivalent is dig +trace +dnssec example.com, which prints the same walk but leaves you to check the digests and signatures yourself.
