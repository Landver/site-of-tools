{{.Title}}

Follows the delegation from a root server down to the zone that owns the name, asking each server directly with recursion off, and checks the DNSSEC chain itself against the IANA root keys rather than trusting a resolver's AD bit. Every hop is shown, with its server, glue and timing.

Using this from the terminal

Same URL, content-negotiated: browsers get the page, everything else gets JSON.

curl 'https://dns.corpberry.com/trace?name=example.com'

curl 'https://dns.corpberry.com/trace?name=example.com&type=MX'

The nearest equivalent is dig +trace +dnssec example.com, which prints the same walk but leaves you to check the digests and signatures yourself.
